## Target claim

The paper's Table 1 reports GOOGL CR 24.36% / SR 6.39 / MDD 1.69% and AAPL CR 26.62% / SR 8.21 / MDD 0.91% over 1 January – 29 March 2024. Those metrics require the full backtest harness, which this study did not run. What this study tests is whether the framework's categorical trading rating is stable across identical runs.

## How to reproduce

1. Clone at the commit above.
2. `python -m venv tradingagents_env && source tradingagents_env/bin/activate`
3. `pip install .`
4. Copy `.env.example` to `.env`; set `DEEPSEEK_API_KEY` and `TRADINGAGENTS_LLM_PROVIDER=deepseek`, both model vars to `deepseek-flash`, `TRADINGAGENTS_TEMPERATURE=0.0`.
5. `python -m cli.main` — ticker, date 2024-02-15, depth 1, provider deepseek.
6. Three runs per ticker.

## What to expect

Report files save on every run where the save prompt is accepted with the default path. The memory log records only the first decision per ticker-date pair: subsequent runs on the same key complete and produce ratings, but their entries are silently dropped by the framework's idempotency guard. The Sentiment and News analysts return null results for historical dates because their vendors serve only recent items, and the macro layer is unavailable without a FRED API key.

## Results summary

Six runs, two tickers, one configuration. The categorical rating was not stable for either ticker:

- GOOGL: Overweight, Hold, Overweight (2 distinct ratings)
- AAPL: Hold, Underweight, Overweight (3 distinct ratings)

The deterministic data layer reproduced exactly across runs: the verified close (GOOGL 141.424, AAPL 181.877), the indicator values, and the technical levels were identical in every run of a given ticker. The instability originates in the LLM reasoning and aggregation layers, not in the market data.

Mean and variance are not meaningful for a categorical output; the distribution above is the result. The paper's reported return metrics (CR, SR, MDD) cannot be compared because this study did not run the backtest harness and used a different backbone model (DeepSeek instead of OpenAI).

## Phase 0 — pilot runs (superseded, not counted)

Before formalizing the experiment, three GOOGL runs were executed at 2024-02-15 with the same config. No pre-state capture was taken. Ratings were Overweight, Overweight, Underweight. Only one memory-log entry survived, and only one report file saved. These runs are not counted in the formal experiment; they motivated the reset.
